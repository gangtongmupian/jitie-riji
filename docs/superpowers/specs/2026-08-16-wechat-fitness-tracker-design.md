# 微信健身记录小程序 — 设计文档

日期:2026-08-16
状态:已与用户逐节确认(5 个设计段落)

## 1. 项目概述

一款发布给公众使用的微信小程序,用于记录每次健身数据:首次登录通过引导问答录入基础信息,按中国健身/健康标准计算体质指标与力量参考;每次训练可记录动作、部位、器械、组数、每组次数与重量;训练结束后可生成分享卡,保存到相册发朋友圈或转发好友。

## 2. 目标与成功标准(MVP)

- 首次引导:用户在 3 分钟内完成基础信息录入并看到体质指标结果
- 单次训练录入:≤ 2 分钟完成一组动作的填写
- 分享卡:训练结束后 10 秒内生成
- 数据可靠:网络异常时不丢记录(本地草稿 + 自动重试)
- 合规:符合微信小程序审核要求(隐私政策、账号注销等)

## 3. 已确认的产品决策

| 决策点 | 结论 |
| --- | --- |
| 使用范围 | 公开发布给公众用户 |
| 标准依据 | 中国标准为主(分级、体脂、力量参考) |
| 记录颗粒度 | 基础版:动作、部位、器械、组数、每组次数、每组重量 |
| 训练计划 | 内置模板库 + 记录时按动作给出推荐重量区间 |
| 分享图 | 单次训练卡为核心;默认简约白卡,可选用户照片作背景 |
| 首页/数据 | 首页本周概览 + 新纪录提示;历史页趋势 + PR 榜 |
| 视觉风格 | 活力橙(白底 + 橙色强调,Keep 类风格) |
| 收费 | MVP 完全免费 |
| 技术路线 | 微信云开发 + 原生小程序(WXML/WXSS/JS) |
| 性别处理 | 标准数据按性别区分;模板以通用为主,男女各有推荐默认计划 |

## 4. 用户流程

### 4.1 首次打开

1. 展示用户协议与隐私政策,同意后进入
2. 微信授权登录,云函数获取 openid 并自动创建账号
3. 引导页 3 步提问(带进度条):
   - 第 1 步:性别(男/女)、年龄、身高、体重
   - 第 2 步:健身目标(增肌/减脂/增力/保持)
   - 第 3 步:每周训练频率
4. 计算结果页"你的起点":BMI 及分级、体脂参考、基础代谢,对照中国标准说明
5. 进入主界面

之后可随时在"我的"页修改资料,重新计算指标。

### 4.2 日常训练

1. 首页点"开始训练"
2. 选择模式:用模板练 / 自由训练
3. 逐动作录入:每组分次填次数、重量;可加组、删组、排序
4. 底部实时显示总组数、总容量
5. 结束训练 → 保存 → 生成分享卡 → 保存相册或转发好友

### 4.3 分享

1. 训练结束自动进入分享卡预览
2. 可选"换背景":纯白底 / 从相册选择照片
3. 生成图片 → 保存到相册(发朋友圈)或转发给好友

## 5. 页面与交互

底部导航 4 个 Tab:首页 / 记录 / 历史 / 我的。

### 5.1 首页

- 问候语(含用户昵称)
- 本周概览卡:本周训练次数、总时长、总容量
- "开始训练"主按钮
- 最近一次训练摘要
- "新纪录!"横幅(如"卧推刷新纪录 60kg × 10")

### 5.2 记录页

- 两种模式:模板训练 / 自由训练
- 模板训练:选择模板(推-拉-腿、全身、上下肢分化等)后开始,动作顺序按模板
- 自由训练:手动添加动作
- 选动作:按部位分类(胸/背/腿/肩/手臂/核心),显示器械类型和推荐重量区间(按性别 + 体重计算)
- 每组录入:重量 + 次数,数字键盘,可加组/删组/拖动排序
- 底部实时统计:总组数、总容量
- 防误退:训练中返回有确认弹窗

### 5.3 历史页

- 月历打卡视图(可切换月份)
- 近 8 周容量 / 时长趋势折线
- PR 排行榜:每个动作的历史最大重量与最重单次容量,标注日期和新纪录徽章

### 5.4 我的页

- 个人资料(性别、年龄、身高、体重、目标、频率,可修改并重算指标)
- 体质指标卡:BMI 及分级、体脂参考、基础代谢,附中国标准对照
- 用户协议、隐私政策入口
- 注销账号
- 关于

## 6. 标准数据(中国标准为主)

### 6.1 体质指标

- BMI = 体重(kg) / 身高(m)²,中国分级:<18.5 偏瘦,18.5–23.9 正常,24–27.9 超重,≥28 肥胖
- 体脂参考范围(按中国常用健康参考值):
  - 男性:偏瘦 <10%,健康 10–20%,偏高 20–25%,肥胖 >25%
  - 女性:偏瘦 <15%,健康 15–25%,偏高 25–30%,肥胖 >30%
- 基础代谢(BMR,采用 Mifflin-St Jeor 公式):
  - 男性 = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
  - 女性 = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161

### 6.2 力量参考

- 每个动作按"性别 + 体重"给出推荐重量区间(如按体重的倍数区间分新手/中级/高级)
- 动作库种子数据中为每个动作配置计算规则;男女标准不同
- 示例(卧推,按体重倍数):
  - 男:新手 0.4–0.6 倍,中级 0.6–0.8 倍,高级 0.8–1.0 倍
  - 女:新手 0.2–0.35 倍,中级 0.35–0.5 倍,高级 0.5–0.65 倍
- 其余动作在种子数据中按动作类型(推/拉/下肢/核心)给出类似规则表

### 6.3 训练模板

- 通用模板库:推-拉-腿、全身分化、上下肢分化等,男女均可自由选择
- 男女推荐默认计划:女计划优先臀腿、核心,男计划优先胸背;仅在默认排序与重点上有侧重
- 引导页收集的"每周训练频率"用于推荐合适的默认模板:3 次/周 → 全身分化,4 次/周 → 上下肢分化,5–6 次/周 → 推-拉-腿

## 7. 分享卡

- 默认版式 A 简约白卡:白底橙色点缀;顶部 App 名 + 日期;中间总容量大字;动作摘要(名称 + 每组重量×次数);底部标语 + 小程序码
- 可选自定义背景:从相册选照片作背景,可预览
- 照片背景自动叠加半透明深色遮罩、切换白色文字,保证可读性
- 小程序码由云函数调用微信接口生成
- 出口:保存到相册(发朋友圈)/ 转发给好友

## 8. 技术架构

### 8.1 技术栈

- 微信小程序原生框架(WXML/WXSS/JS)
- 微信云开发:云函数、云数据库、云存储
- 分享图:小程序端 Canvas 绘制;自定义背景图存云存储

### 8.2 数据模型(云数据库集合)

| 集合 | 字段要点 |
| --- | --- |
| users | openid、性别、年龄、身高、体重、目标、每周频率、BMI 及分级、体脂参考、基础代谢、创建/更新时间 |
| exercises | 动作名称、部位、器械类型、推荐重量计算规则(种子数据,全局共享) |
| templates | 模板名、适用目标、推荐性别标记(通用/男/女)、动作清单(默认组数、次数区间)、是否默认 |
| workouts | 日期、时长、模式(模板/自由)、模板名、动作明细(每组重量和次数)、总组数、总容量 |
| prs | 用户、动作、历史最大重量、最重单次容量、达成日期 |

### 8.3 云函数

- login:获取 openid、创建/返回用户
- standards:计算体质指标 + 推荐重量区间
- catalog:返回动作库与模板
- saveWorkout:保存训练记录并更新 PR
- stats:首页概览、历史趋势、PR 榜
- qrcode:生成小程序码

### 8.4 数据流

小程序页面 → 云函数 → 云数据库;数据严格按 openid 隔离,云数据库权限设为"仅本人可读写"。

## 9. 异常处理与安全

- 保存训练失败自动重试;断网时记录存本地草稿,下次打开提示补传
- 输入范围校验:年龄 6–100、身高 80–250cm、体重 20–300kg、次数 1–100 等
- 数据权限:云数据库仅创建者可读写,查询按 openid 过滤
- 隐私:首次登录前展示用户协议/隐私政策,明示年龄/身高/体重用途,提供注销账号入口,不收集无关信息

## 10. 测试策略

### 10.1 单元测试

- 标准计算:BMI 分级边界、男女体脂参考、推荐重量区间(不同性别/体重组合)
- 统计计算:总容量、PR 更新逻辑

### 10.2 云函数测试

- 登录建号、保存训练、统计与 PR 计算

### 10.3 界面与真机测试

- 首次引导全流程、模板/自由训练、分享卡生成与自定义背景
- 微信开发者工具 + 真机预览

## 11. 上线合规清单(用户需准备)

- 注册微信小程序账号(个人主体即可),取得 AppID
- 选择类目:健身 / 健康管理
- 准备并提交隐私政策、用户协议
- 云开发自带域名与存储,无需买服务器、无需 ICP 备案
- 首次提审材料按微信最新要求准备

## 12. 明确不做(MVP 之外,后续版本)

- 自动生成个性化训练计划(A 方案)
- 社交动态、关注、评论
- 付费会员与支付
- App / 网页等多端
- 训练视频与动作教学
- 体脂秤 / 可穿戴设备数据接入

## 13. 术语

- openid:微信用户的匿名唯一标识
- PR:Personal Record,个人最好成绩
- 总容量:一次训练中所有组"重量 × 次数"之和
- 体脂参考:根据身高体重和性别估算的体脂率参考区间
