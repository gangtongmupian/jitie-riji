## 目标

1. 吸引更多用户使用（拉新）
2. 提升使用粘性（留存）
3. 积累原始客户资源（私域沉淀）

## 方案概览

产品内增长机制 + 运营打法手册，不依赖付费投放：

- 邀请有礼：分享链路携带邀请码，双方解锁进阶计划
- 连续打卡 + 成就勋章：首页可见、分享可传播
- 训练提醒：订阅消息，云端定时发送
- 私域沉淀：交流群 / 客服入口
- 增长运营手册：外部执行打法文档

## 功能明细

### 1. 邀请有礼

- 分享路径统一携带 `inviter=<openid>`（转发 + 朋友圈 + 二维码 scene）
- 新用户首次打开时记录邀请人到本地；建档（saveProfile/login）时建立云端邀请关系
- 新增 `invites` 集合：`{ inviter, invitee, createdAt }`
- 双方用户文档标记 `inviteReward: true`，解锁「进阶计划」2 套模板（增肌进阶 / 减脂进阶，`premium: true`）
- 新页面 `pages/invite/invite`：专属二维码、已邀请人数、解锁状态、转发按钮
- `qrcode` 云函数扩展：按 scene 生成邀请码（默认 scene=分享）
- 未解锁用户看到锁住的进阶模板，点击引导去邀请

### 2. 连续打卡 + 成就勋章

- `stats` 云函数新增：`streak`（含今天）、`maxStreak`、`totalWorkouts`、`achievements`
- 成就规则：首次训练 / 连续 3 天 / 连续 7 天 / 连续 30 天 / 累计 100 组 / 累计举起 10 吨
- 首页展示连续天数与勋章；分享卡加入连续天数文案

### 3. 训练提醒（订阅消息）

- 「我的」页新增开启入口：`wx.requestSubscribeMessage`，成功后保存 `remindEnabled: true`
- 新增 `remind` 云函数 + 每日 20:00 定时触发器：给当天未训练且已订阅的用户发提醒
- 模板 ID 未配置时功能自动隐藏/跳过，不影响上线

### 4. 私域沉淀

- 「我的」页新增：加入交流群（群二维码图，可配置）、联系客服（复制微信号，可配置）
- 配置集中在 `miniprogram/config.js`，未配置时对应入口隐藏

### 5. 增长运营手册

- `docs/growth-playbook.md`：小红书 / 朋友圈 / 微信群裂变文案、赛事方案、数据周报口径

## 数据与权限

- 新增集合：`invites`
- 用户文档新增字段：`inviteReward`、`remindEnabled`
- 所有数据仍按 openid 隔离，普通用户互不可见
- 隐私口径不变：仅收集实现功能所必需的信息

## 验收

- 邀请链路端到端成立（分享→绑定→解锁→邀请页显示）
- 连续打卡计算正确（含跨天、今天未练但昨天练的边界）
- 订阅消息：模板配置后定时发送；未配置时静默隐藏
- 单元测试 + UI 自动化全绿；上传 v1.2.6
