# 牛来举铁 · 增长运营手册

版本：v1.0（2026-08-24）

> 配合 v1.2.6 增长功能使用。产品内已经实现：邀请裂变、连续打卡/成就、训练提醒、私域入口。本手册负责「人」的部分——把功能用起来。

## 1. 北极星指标

**每周至少训练 1 次的活跃用户数**（周活跃训练用户）。它是拉新与留存的共同结果，直接决定赛事与变现价值。

辅助指标：

- 新增用户数（建档人数）
- 邀请转化率 = 被邀请完成建档人数 / 分享点击数
- 7 日留存率
- 周打卡率 = 本周训练≥1 次用户 / 全部建档用户
- 连续打卡 7 天用户数

## 2. 冷启动期（第 1–2 周）

目标：让第一批 100 个「种子用户」完成建档并各练 1 次。

### 2.1 私域种子池

1. 建 1 个「牛来举铁 · 训练交流群」（群二维码上传后填入 `miniprogram/config.js` 的 `GROUP_QR`）。
2. 拉身边的健身朋友进群，作为种子用户。
3. 每周在群里发起 1 次「本周打卡接龙」，用小程序生成打卡图晒成绩。

### 2.2 朋友圈打法

每天 1 条，文案模板（直接可用）：

> 连续训练第 N 天。今天腿 + 背，容量 12 吨。小程序记录第 X 天，越练越有数。想一起打卡的加我，送你解锁进阶计划。💪

配图：训练打卡分享图（小程序「分享/保存图片」生成）。

### 2.3 微信群打法

不要硬广。用「帮忙挑动作」切入：

> 兄弟们，我这个硬拉动作标准吗？最近用小本本记训练数据，发现容量上得挺快。有一起记录打卡的吗？

然后发分享图 + 小程序卡片。被问「这是什么」时回复：一个健身记录小程序，我天天用，邀请你一起，双方能解锁进阶计划。

## 3. 裂变期（第 3–6 周）

目标：靠「邀请解锁进阶计划」形成自然传播。

### 3.1 规则话术（对外统一）

> 牛来举铁「邀请有礼」：你邀请 1 位好友完成建档，你和好友同时解锁「进阶计划」2 套模板（增肌/减脂）。邀请越多，你「我的」页的邀请人数越高。

### 3.2 每周一场小活动

「本周最卷打卡王」：周日 24 点结算，本周训练次数最多的 3 人，群内点名表扬 + 群主发小红包（10–50 元）。低成本、高氛围。

### 3.3 小红书/视频号内容矩阵

账号定位：普通人的健身记录。

选题模板（每周 2–3 篇）：

- 《健身 30 天身体变化（数据版）》：用小程序历史页的统计截图
- 《新手去健身房怎么练？我的 4 天模板》：训练页模板截图
- 《健身房器械认不全？图解 26 台 ROSEN 固定器械》：动作库截图
- 《我如何做到连续打卡 30 天》：成就页截图

笔记末尾统一引导：评论区扣「打卡」，私信发小程序链接。

## 4. 留存期（第 7 周起）

目标：周打卡率 ≥ 40%。

- 训练提醒：引导用户开启（我的 → 训练提醒）。每周发 1 次群公告提醒。
- 连续打卡：鼓励用户把「连续 X 天」晒到朋友圈，形成个人品牌绑定。
- 每月「成就月报」：群内公布本月 PR 榜（小程序「个人最好成绩」数据）。

## 5. 微信赛事方案

报名「微信赛事」时，把小程序作为打卡工具，说明文档口径：

> 牛来举铁是一款微信小程序健身记录工具，参赛者通过小程序每日打卡，系统自动统计训练次数、容量与连续天数，赛事方以小程序数据作为完赛依据。

赛事配套动作：

1. 赛事期间每日 20:00 定时提醒（需配置订阅消息模板）。
2. 建赛事专属群，用「打卡接龙 + 分享图」维持活跃。
3. 赛事结束发「完赛证书分享图」（可基于分享卡改造）。

## 6. 数据周报（每周一输出）

从云开发控制台「数据库」导出：

- `users` 集合：建档人数、新增人数
- `workouts` 集合：训练次数、活跃用户数、周打卡率
- `invites` 集合：邀请关系数、转化漏斗

周报格式：本周新增 / 活跃 / 打卡率 / 邀请数 / 下周动作。

## 7. 上线前待配置清单

| 项目 | 位置 | 说明 |
|---|---|---|
| 订阅消息模板 ID | 微信公众平台「订阅消息」→ 填入 `miniprogram/config.js` 的 `TRAIN_REMIND_TMPL`，并重新部署 `remind` 云函数 | 不配置则提醒入口自动隐藏 |
| 交流群二维码 | 群二维码图片（云存储 fileID 或 https）→ `GROUP_QR` | 不配置则入口隐藏 |
| 客服微信号 | → `SERVICE_WECHAT` | 不配置则入口隐藏 |
| 微信赛事说明文档 | 见上方第 5 节 | 报名时上传 |

## 8. 合规提醒

- 不购买不明来源的刷量服务，可能导致封号。
- 邀请奖励只解锁虚拟内容（模板），不涉及现金返利，规避平台合规风险。
- 所有用户数据按 openid 隔离，禁止导出或公开用户训练数据。
