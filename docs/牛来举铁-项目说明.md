## 一、项目概览

「牛来举铁」是一款基于微信云开发的健身训练日志小程序，围绕「**记一次训练 → 看见进步 → 分享成果**」的最短闭环设计。用户打开即记，按部位与器械图示快速添加动作，自动汇总训练次数与消耗，沉淀个人最好成绩（PR），并把成果做成可分享的图片。

## 二、创作背景

1. **铁馆用户记录难**：健身房自由器械与固定器械种类繁多，用户常靠纸笔或记忆记录组数、重量、次数，难以长期积累与复盘。
2. **动作库抽象、器械认不出**：市面动作库多为抽象名词或火柴人示意图，新手面对 ROSEN、FORWARD 等品牌固定器械时对不上型号，容易用错动作。
3. **男女训练差异被忽视**：男女的力量基数、训练目标与器械选择差异明显，通用模板无法满足实际需求。
4. **成果难以分享**：训练记录停留在 App 内部，缺少一键生成分享图、转发微信好友与朋友圈的传播链路。

## 三、创作思路

### 3.1 核心闭环

`打开即记（1–2 分钟）→ 动作库图文识别 → 长期统计与 PR → 分享图/转发`

### 3.2 产品原则

1. **记录要快**：打开到记完一组不超过几次点击；任何新功能必须换取明显价值。
2. **数据真实可信**：训练次数按完成训练计数（不按组数），统计口径一致，不夸大消耗。
3. **新手友好**：图示优先于文字，每个器械/动作都能被认出来；演示动画 + 文字要领双通道。
4. **尊重用户数据**：本地草稿优先、云端同步、记录可修改、可云端注销删除。
5. **克制表达**：采用 Notion 设计语言（awesome-design-md），紫色只用于主导行动，不堆视觉噪音。

### 3.3 差异化定位

「打开即记」的铁馆训练日志。差异点：按真实铁馆器械建库（含 ROSEN 与 FORWARD 固定器械，带官图与动作动画演示）、男女模板分开、自由+模板双模式、离线自绘动画演示（无版权与域名限制）。不做重社交、重内容生态，记录和进步是唯一主线。

## 五、功能清单（最新）

### 5.1 首次建档引导

- 隐私协议勾选 → 性别 / 年龄 / 身高 / 体重 / 健身目标
- 自动计算 BMI、体脂参考区间、基础代谢 BMR
- 性别决定训练模板与推荐重量区间

### 5.2 专业动作库（206 个）

- 覆盖胸 / 背 / 腿 / 臀腿 / 肩 / 手臂 / 核心 7 大部位
- 含中英文术语、器械分类、男女差异化推荐重量区间
- 每个动作带三帧演示动画 + 文字要领 + 器械图示
- 品牌固定器械带官网实拍图与型号（如 `FORWARD分动式推胸机 FWHM-001`）
- 支持自定义动作

### 5.3 训练记录

- 自由训练 / 模板训练双模式
- 组间歇计时器（分 0–30 + 秒 0–55 可调，离开页面按剩余时间恢复，到点震动提醒）
- 每组记录次数 / 重量，重量口径有明确提示（杠铃记总重量、哑铃记单只、器械记配重）
- 完成训练时录入或自动预估本次消耗热量（kcal）

### 5.4 训练模板（10 套）

- 全身分化男/女版、推-拉-腿 PPL、上下肢分化
- ROSEN 铁馆器械男/女版、FORWARD 器械男/女版
- 进阶计划（增肌/减脂），按性别排序并带性别标签

### 5.5 历史统计

- 本周 / 本月 / 本年三档统计（训练次数 + 消耗 kcal）
- 训练日历：打卡加深色显示，点击日期查看当天训练内容
- 个人最好成绩 PR（最大重量 / 最重单次容量）
- 连续训练天数与成就

### 5.6 分享与传播

- 训练成果分享图（白卡 / 照片背景可选），一键保存相册或转发好友
- 所有页面支持右上角转发 / 朋友圈
- 邀请好友二维码（云函数生成小程序码，邀请解锁进阶模板）

### 5.7 数据与合规

- 本地草稿兜底，断网不丢数据，启动自动补传云端
- 用户信息可云端注销删除（deleteAccount 云函数），隐私保护指引已配置

## 七、数据标准

- **BMI**：中国标准分级（偏瘦 <18.5 / 正常 18.5–23.9 / 超重 24–27.9 / 肥胖 ≥28）
- **体脂参考**：中国常用健康参考值（男女分表）
- **BMR**：Mifflin-St Jeor 公式
- **推荐重量区间**：按「性别 × 训练水平」的体重倍数规则，取 2.5kg 档；自重动作不给出重量

## 八、技术架构

- 微信原生小程序（WXML/WXSS/JS，基础库 3.17.1）
- 微信云开发：云函数 + 云数据库（NoSQL）
- 7 个页面：onboarding / home / record / history / profile / share / invite
- 10 个云函数：login / saveProfile / catalog / saveWorkout / stats / initDb / qrcode / invite / remind / deleteAccount
- 动作库与模板在 `miniprogram/data` 单一来源，`initDb` 幂等同步到云端
- 自动化验证：32 项单元测试（含动作完整性、FORWARD 型号对照、动画/图示资源校验）
- 设计语言：Notion 风格（DESIGN.md），全 rpx + 安全区适配，无横向滚动
